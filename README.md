## 🇧🇷 Conversor de Temperatura

Aplicação desktop desenvolvida em **JavaFX** como projeto de estudo, explorando conceitos de interface gráfica, estilização com CSS e lógica de conversão de unidades.

### 📸 Preview

> _Adicione um screenshot da aplicação aqui_

### 🚀 Funcionalidades

- Conversão de **Celsius → Fahrenheit**
- Conversão de **Fahrenheit → Celsius**
- Validação de entrada (campos vazios e valores não numéricos)
- Interface estilizada com tema **pixel art / Dev Respawn**

### 🛠️ Tecnologias

| Tecnologia | Versão |
|------------|--------|
| Java | 17 |
| JavaFX | 17+ |
| Scene Builder | - |
| IntelliJ IDEA | - |

### ▶️ Como executar

**Pré-requisitos:** JDK 17 e JavaFX SDK instalados.

```bash
# Clone o repositório
git clone https://github.com/semendeZ0/conversor-temperatura

# Abra no IntelliJ IDEA e execute a classe MainApplication
```

> Certifique-se de que o JavaFX está configurado corretamente no seu SDK.

### 📁 Estrutura do projeto

```
src/
└── main/
    ├── java/
    │   └── conversormain/conversor/
    │       ├── Controller.java
    │       └── MainApplication.java
    └── resources/
        └── conversormain/conversor/
            ├── font/
            │   └── PressStart2P-Regular.ttf
            ├── telaConversor.fxml
            ├── style.css
            └── icon.png
```

### 📚 O que aprendi

- Estrutura de projetos JavaFX com FXML e Controller
- Estilização de componentes com JavaFX CSS
- Uso de `ComboBox`, `TextField` e `Label` com `@FXML`
- Tratamento de exceções e validação de entrada
- Carregamento de fontes customizadas (`.ttf`) em JavaFX
